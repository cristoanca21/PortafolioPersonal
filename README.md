# Portafolio Personal · Cristopher Angeles Castillo

Portafolio web personal de **Cristopher Angeles Castillo**, estudiante de Diseño y Desarrollo de Software en Tecsup (Trujillo, Perú).

## 🚀 Tecnologías utilizadas

- **HTML5 & CSS3** (Modular, variables CSS, animaciones con Intersection Observer)
- **JavaScript (ES6+)** (Renderizado dinámico de proyectos, modo oscuro/claro con `localStorage`)
- **Font Awesome 6** (Iconografía)
- **Google Fonts** (Playfair Display & Inter)

## 📁 Arquitectura del proyecto

```text
PortafolioPersonal/
├── index.html          # Estructura principal
├── css/
│   ├── variables.css   # Design tokens y variables de tema (claro/oscuro)
│   ├── base.css        # Resets y estilos base
│   ├── layout.css      # Sistema de grillas y secciones
│   ├── components.css  # Botones, navbar, cards de proyectos
│   ├── sections.css    # Hero, timeline de experiencia, contacto y footer
│   ├── animations.css  # Animaciones de scroll y transiciones
│   └── responsive.css  # Adaptabilidad móvil y tablet
└── js/
    ├── data.js         # Colección de proyectos
    ├── theme.js        # Selector de tema claro / oscuro
    ├── projects.js     # Renderizado dinámico de tarjetas de proyectos
    ├── animations.js   # Detección de scroll (Intersection Observer)
    └── nav.js          # Control de barra de navegación y menú móvil
```
